# スマート献立コンシェルジュ (Meal Planner v2)

HTML/CSS/JSで構築された、あなたのライフスタイルに合わせた献立を提案するアプリです。

## 特徴
- **パーソナライズ提案**: 「一人暮らし」「シニア夫婦」「時短重視」「健康配慮」などのプロフィールに合わせて、最適な一週間の献立を自動で作成します。
- **条件ベース生成**: 内部の料理データベースから、あなたの条件に合致するメニューをスマートに抽出。
- **履歴保存機能**: 過去の献立をログとして保存し、いつでも振り返ることができます。
- **LocalStorage完結**: サーバー不要。データはすべてブラウザ内に安全に保存されます。

## 使い方
1. **プロフィールを設定**: 画面上部の「あなたのプロフィール」から、世帯構成や重視するポイントを選択します。
2. **献立を自動提案**: 「献立を自動提案」ボタンを押すと、プロフィールに合わせたメニューが一週間分セットされます。
3. **自由に編集**: 提案されたメニューを書き換えたり、足りない部分を手動で入力することも可能です。
4. **履歴へ保存**: 一週間が終わったら「完了して履歴へ」ボタンでアーカイブします。

## 開発・公開方法
1. このリポジトリをクローンまたはダウンロードします。
2. GitHubリポジトリにアップロードします。
3. リポジトリの `Settings` > `Pages` から公開設定を有効にします。
