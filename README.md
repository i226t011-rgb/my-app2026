# 一週間の献立メーカー (Meal Planner)

HTML/CSS/JSで構築された、シンプルで美しい一週間の献立作成アプリです。GitHub Pagesで簡単に公開できます。

## 特徴
- **シンプル & クリーン**: 直感的で使いやすいインターフェース。
- **履歴保存機能**: 過去の献立をログとして保存し、いつでも振り返ることができます。
- **LocalStorage完結**: データはすべてブラウザ内に保存されるため、サーバー設定は不要です。
- **モバイル対応**: スマートフォンやタブレットでも快適に利用できます。

## 使い方
1. 各曜日の朝・昼・晩のスロットにAIが考えた献立を入力します（自動保存されます）。
2. 一週間が終わったら「今週を完了して保存」ボタンを押すと、履歴にアーカイブされます。
3. 過去のログは画面下部の履歴セクションから確認・管理できます。

## 開発・公開方法
1. このリポジトリをクローンまたはダウンロードします。
2. GitHubリポジトリにアップロードします。
3. リポジトリの `Settings` > `Pages` から公開設定を有効にします。
